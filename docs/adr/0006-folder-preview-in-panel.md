# 折りたたみフォルダのホバープレビューをパネル内カードで出す

折りたたみフォルダの中身を開かずに確かめて開けるようにするため、フォルダ行に500msホバーすると Folder Preview を出す。Chrome のサイドパネルはパネル外へ描画できないため、Arc のように本文側へはみ出すポップアップではなく、フォルダ行の直下に浮くパネル内カードとし、幅は最大320px、高さは最大5行分、収まらない場合は上へ反転して内部スクロールにする。表示は配下の Pin / Bookmark をツリー順に平坦化した一覧で、クリックで開く・切り替えるだけに絞り、検索欄・×・ミュート・右クリック・ドラッグは持たない。

## 理由

- サイドパネルは独立したページで、CSS でパネルの外に要素を出せない。Arc の見た目をそのまま再現するのではなく、同じ「フォルダを開かずに中身へ触れる」目的をパネル内で満たす。
- ホバーで出す一時 UI に破壊的操作やドラッグを載せると誤操作と実装の複雑さが増すため、行の操作はクリックによる開く・切り替えるだけにする。
- Peek 行は開いている Pin の現在地を常時示す役割として残し、Folder Preview は閉じている Pin も含む全体を見せる役割に分ける。
- 検索欄は今回の目的（フォルダを開かずに開く）に不要なため付けない。件数が増えた場合は内部スクロールで対応する。
- 500ms の遅延は、フォルダの上を横切っただけで表示されるちらつきを防ぐためのもの。閉じる側は150msの猶予を置き、フォルダ行とカードの間をポインタが移動できるようにする。
