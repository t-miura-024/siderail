# タブ管理を Chrome 方式と Arc 方式から選べるようにする

## 背景

Siderail はこれまで、Chrome のブックマークバーとタブをそのまま縦に並べるだけだった。常時使うサイトがタブ一覧を占有し、作業中のタブが埋もれるという不満があり、Arc のように「永続する Pinned」と「使い捨ての Today」を分けたい。

## 決定

- タブ管理を `arc` と `chrome` の2モードにし、options ページで切り替える。保存値がないときの既定は `arc`。
- Arc 方式の Pinned は、既存の Bookmark Bar 配下のツリーをそのまま使う。ブックマークが唯一の真実源で、Chrome 同期と既存の編集 UI をそのまま流用する。
- Pin から開いたタブは Chrome のピン留めタブとして開き、Today からは除外する。Pin とタブの対応は `chrome.storage.session` に `bookmarkId -> tabId` で保存し、タブが閉じるまで維持する。
- ブラウザ再起動でタブ ID が変わった場合は、URL が一致する Pin がちょうど1件のときだけ結び直す。
- カスタム名は `chrome.bookmarks.update` で title を書き換える。絵文字アイコンは扱わない。
- Pinned の × はライブタブを閉じるだけで、Pin は残す。ピン解除はドラッグアウトまたは右クリックメニューで行い、ブックマークを削除してタブを Today に残す。取り消し用のトーストを6秒間表示する。
- Chrome 側でピン留めされたまま対応するブックマークがないタブは、Pinned の末尾に未マップのピンとして表示し、ブックマークとして保存できる。
- ワークスペース、Auto-archive、Archive、Split View、Peek、独自キーボードショートカットは扱わない。

## 理由

- Pinned の実体をブックマークにすることで、データの移行が不要になり、Chrome の同期・既存のフォルダ・編集 UI をそのまま使える。
- ピン留めタブをネイティブの pinned タブにすることで、「Pinned は Today に出ない」「閉じてもピンは残る」という Arc の意味論を、タブの寿命と矛盾させずに表現できる。
- マップを URL 一致の都度導出ではなく明示的に保持することで、ピンしたタブがサイト内を移動しても Pinned のままでいられる。URL 一致は再起動時の復元にだけ使う。
- Chrome 拡張ではネイティブのタブストリップを置き換えられず、`Cmd+1..9` や `Ctrl+Tab` も予約されている。サイドパネルが主でネイティブ側と併存する前提に立つことで、実現できない機能を設計に持ち込まない。

## 影響

- Arc 方式では、ピン解除が Chrome のブックマーク削除を伴う。誤操作を防ぐため、ドラッグアウトとメニュー操作の両方に取り消しを用意する。
- ブックマークを直接編集すると Pin の表示も変わる。Chrome 方式と Arc 方式は同じデータを共有する。
- ネイティブのタブストリップと Siderail の並び順は一致しないことがある。ネイティブ側の操作は Siderail に追従するが、その逆は保証しない。
