# タブ管理を Chrome 方式と Arc 方式から選べるようにする

## 背景

Siderail はこれまで、Chrome のブックマークバーとタブをそのまま縦に並べるだけだった。常時使うサイトがタブ一覧を占有し、作業中のタブが埋もれるという不満があり、Arc のように「永続する Pinned」と「使い捨ての Today」を分けたい。

## 決定

- タブ管理を `arc` と `chrome` の2モードにし、options ページで切り替える。保存値がないときの既定は `arc`。
- Arc 方式の Pinned は、既存の Bookmark Bar 配下のツリーをそのまま使う。ブックマークが唯一の真実源で、Chrome 同期と既存の編集 UI をそのまま流用する。
- Pin から開いたタブは Chrome のピン留めタブとして開き、Today からは除外する。Pin とタブの対応は `chrome.storage.session` に `bookmarkId -> tabId` で保存し、タブが閉じるまで維持する。
- ブラウザ再起動でタブ ID が変わった場合は、URL が一致する Pin がちょうど1件のときだけ結び直す。
- カスタム名は `chrome.bookmarks.update` で title を書き換える。絵文字アイコンは扱わない。
- Pinned の × はライブタブを閉じるだけで、Pin は残す。ピン解除はドラッグアウトまたは右クリックメニューで行い、ブックマークを削除してタブを Today に残す。取り消し用のトーストを6秒間表示する。
- Chrome 側でピン留めされたまま対応するブックマークがないタブは、Pinned の末尾に未マップのピンとして表示し、ブックマークとして保存できる。
- ワークスペース、Auto-archive、Archive、Split View、Arc のタブ Peek（タブ内容のプレビュー）、独自キーボードショートカットは扱わない。

## 理由

- Pinned の実体をブックマークにすることで、データの移行が不要になり、Chrome の同期・既存のフォルダ・編集 UI をそのまま使える。
- ピン留めタブをネイティブの pinned タブにすることで、「Pinned は Today に出ない」「閉じてもピンは残る」という Arc の意味論を、タブの寿命と矛盾させずに表現できる。
- マップを URL 一致の都度導出ではなく明示的に保持することで、ピンしたタブがサイト内を移動しても Pinned のままでいられる。URL 一致は再起動時の復元にだけ使う。
- Chrome 拡張ではネイティブのタブストリップを置き換えられず、`Cmd+1..9` や `Ctrl+Tab` も予約されている。サイドパネルが主でネイティブ側と併存する前提に立つことで、実現できない機能を設計に持ち込まない。

## 影響

- Arc 方式では、ピン解除が Chrome のブックマーク削除を伴う。誤操作を防ぐため、ドラッグアウトとメニュー操作の両方に取り消しを用意する。
- ブックマークを直接編集すると Pin の表示も変わる。Chrome 方式と Arc 方式は同じデータを共有する。
- ネイティブのタブストリップと Siderail の並び順は一致しないことがある。ネイティブ側の操作は Siderail に追従するが、その逆は保証しない。

## 表示仕様

- Open Pin と Closed Pin は、閉じている Pin の favicon とタイトルを暗くすることで示す。開いている Pin は通常の明るさ、アクティブな Pin は行の背景でハイライトする。
- Navigated Pin は、favicon を現在のサイトのものにする。favicon 側の左セグメントへのホバーでピン元の favicon にクロスフェードする。行の高さは40px固定のまま、favicon と操作ボタンは固定で、タイトルだけを少し上へ寄せ、その下に「ピン元の URL に戻す」を出す。⌘ / Ctrl 押下中は「ピンから切り離す」に変わり、⌘ / Ctrl + クリックで現在のページを通常タブとして切り離してピン元に戻す。行のタイトルは Pin のタイトルを維持する。
- Pin 行の左端には favicon を含むセグメントがあり、このセグメント全体がボタンで、遷移中はピン元に戻し、⌘ / Ctrl + クリックで切り離す。閉じているときは開き、開いていて遷移していないときはタブに切り替える。背景色は、ピン元と異なる URL を表示しているとき（リセットが機能するとき）のホバー中だけ表示する。
- Pin 行の右端には × を含むセグメントがあり、行の右端から行の高さいっぱいに広がる。行のホバー中だけ × が見え、セグメント全体をクリックするとライブタブを閉じる。Pin は残る。再生中・ミュート中のタブでは、セグメント内にスピーカーボタンも並ぶ。
- すべての行は40px固定。Pinned、Bookmark Section、Today、Tab Section、New Tab 行、Peek 行、Folder Preview の行を含む。
- Row Indent は、行要素全体を `margin` で右へずらし、内容の `padding` は10px固定にする。1段16px。背景・ホバー・アクティブのピルも行要素と一緒に動く。Chrome 方式のブックマーク行にも適用する。
- 折りたたみフォルダが開いている子孫 Pin を持つ場合、その Pin を Peek 行としてフォルダ直下に表示する。Peek 行はツリー順で、ネストしたフォルダ内の Pin も含む。インデントは Pin 本来の深さに従い、中間フォルダ行は表示しない。閉じている Pin は含めない。
- Peeked Folder は三点入りフォルダアイコンで示す。展開中や、開いている子孫がない折りたたみフォルダは通常のフォルダアイコンを使う。
- Peek 行は通常の Pin 行と同じ操作（クリック、閉じる、ミュート、ドラッグ、右クリック）ができる。
- 折りたたみ中のフォルダに500msホバーすると Folder Preview を出し、配下の Pin をツリー順に平坦化して表示する。詳細は ADR 0006。
- 現在のウィンドウ外にあるピン留めタブは Closed Pin として扱う。
